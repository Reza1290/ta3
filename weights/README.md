# Shared Model Checkpoints

Direktori ini menyimpan bobot model PyTorch (.pth) yang telah dilatih (~800 MB):
- `swin_small_binary_best.pth` (Stage 1 Swin-S binary Contact/Non-contact)
- `swin_s_mha_binary_best.pth` (Stage 1 Swin-S + Multi-Head Attention)
- `vit_base_binary_best.pth` (Stage 1 ViT-Base/16)
- `stage2_dl_best.pth` (Stage 2 Resorption Classifier)
- `resnet18_best.pth` (Baseline 2D CNN)

> [!NOTE]
> File `.pth` diabaikan oleh Git. Untuk mengunduh bobot model terlatih, lihat rilis di GitHub Releases atau Hugging Face repo.
